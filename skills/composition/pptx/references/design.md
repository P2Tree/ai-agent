# 设计指导

创建 PPT 演示文稿时的设计决策参考。

## 配色

选取与主题匹配的调色板，不要默认蓝色。

### 调色板参考

| 森林苔藓 | `2C5F2D` | `97BC62` | `F5F5F5` |
| 珊瑚活力 | `F96167` | `F9E795` | `2F3C7E` |

### 配色原则

- 一色主导（60-70% 视觉权重），1-2 辅助色，1 强调色
- 不要所有色等权
- 深色标题+结论页，浅色内容页（"三明治"结构）
- 或全程深色营造高端感

## 视觉主题

选一个重复性元素贯穿全部幻灯片：圆角图片框、彩色圆圈图标、粗单边框线。

## 布局

**每张幻灯片必须有视觉元素** — 图片、图表、图标或形状。纯文本幻灯片不会被记住。

### 布局选项

- 双栏（左文字，右图示）
- 图标+文字行（彩色圆圈图标、粗标题、描述在下）
- 2×2 或 2×3 网格
- 半出血图片（左或右侧全幅）+ 内容叠加

### 数据展示

- 大数字标注（60-72pt 数字 + 小标签）
- 对比栏（前后、优缺、并排选项）
- 时间线或流程（编号步骤、箭头）

### 视觉润色

- 章节标题旁的彩色圆圈小图标
- 关键数据或标语用斜体强调文字

## 字体

选择有性格的标题字体 + 清晰的正文字体。

| 标题字体 | 正文字体 |
|----------|----------|
| Georgia | Calibri |
| Arial Black | Arial |
| Calibri | Calibri Light |
| Cambria | Calibri |
| Trebuchet MS | Calibri |
| Impact | Arial |
| Palatino | Garamond |
| Consolas | Calibri |

| 元素 | 字号 |
|------|------|
| 幻灯片标题 | 36-44pt bold |
| 章节标题 | 20-24pt bold |
| 正文 | 14-16pt |
| 说明文字 | 10-12pt muted |

## 间距

- 最小边距 0.5"
- 内容块间距 0.3-0.5"
- 留白——不要填满每一寸

## 避坑

- 不要每张同布局 — 变换列、卡片、标注
- 正文不要居中 — 左对齐，仅标题居中
- 标题和正文字号对比要大 — 标题 36pt+ vs 正文 14-16pt
- 不要默认蓝色 — 选与主题相关的色
- 间距要一致 — 选 0.3" 或 0.5"，全篇统一
- 不要只修一张其余随便 — 全做或全简
- 不要纯文本幻灯片 — 加图片、图标、图表
- 文本框对齐形状时注意 padding — 设 `margin: 0` 或偏移补偿
- 文字和图标都要高对比度
- **不要在标题下加装饰线** — 这是 AI 生成幻灯片的标志；用空白或背景色代替
