# 报告类型详解

## 日报

**目的：** 同步当日进展，暴露阻塞项。

**必需章节：**
1. 今日完成 — 具体事项 + 产出
2. 明日计划 — 具体事项 + 预期产出
3. 需要支持 — 阻塞项 + 影响范围 + 需要的支持

**数据要求：** 完成项数量、阻塞时长。无需对比基准。

**典型受众：** 直属上级

**与周报的区别：** 粒度最细，侧重执行动作，无需闭环和对比分析。

---

## 周报

**目的：** 总结一周进展，闭环上周承诺，暴露风险。

**必需章节：**
1. 本周进展 — 关键事项 + 指标数据 + 环比
2. 风险点 — 影响范围 + 建议方案 + 需要的支持
3. 下周计划 — 事项 + 责任人 + 截止日期
4. 上周承诺闭环 — 每条承诺的完成/进行中/未完成状态

**数据要求：** 关键指标 + 环比。表格呈现。

**典型受众：** 直属上级 / 团队负责人

**与日报的区别：** 增加闭环章节和环比对比。
**与月报的区别：** 粒度更细，侧重执行层面，不要求目标达成分析。

---

## 月报

**目的：** 月度复盘，对比目标与实际，指导下月方向。

**必需章节：**
1. 月度进展 — 核心指标 + vs 目标 + vs 上月
2. 目标达成对比 — 各项目标/实际/达成率，表格呈现
3. 风险与待协调 — 影响范围 + 建议方案 + 需要的支持
4. 下月计划 — 事项 + 责任人 + 截止日期
5. 上月承诺闭环 — 每条承诺的完成/进行中/未完成状态 + 未完成原因

**数据要求：** 所有核心指标 + vs 目标 + vs 上月。目标达成率必须体现。

**典型受众：** 团队负责人 / 部门负责人

**与周报的区别：** 增加目标达成对比，数据要求更高，问题分析更深入。

---

## 季度报告

**目的：** 季度战略复盘，调整方向，申请资源。

**必需章节：**
1. 季度核心成果 — 3-5 个核心成果 + 数据支撑
2. 目标达成全景 — 全指标 vs 目标 vs 上季度，表格呈现
3. 下季度重点 — 战略方向 + 关键里程碑 + 资源需求
4. 风险与待协调 — 影响范围 + 建议方案 + 需要的决策/资源
5. 上季度承诺闭环 — 每条承诺的完成/进行中/未完成状态

**数据要求：** 全指标 + vs 目标 + vs 上季度 + 行业对比（如有）。需要趋势图描述。

**典型受众：** 部门负责人 / 高层

**与月报的区别：** 增加战略框架、资源需求、行业对比。语言更精炼。

---

## 年度总结

**目的：** 年度全景回顾，个人/团队贡献沉淀，规划来年方向。

**必需章节：**
1. 年度核心成果 — 3-5 个核心成果 + 全年数据 + vs 目标 + vs 去年
2. 目标达成全景 — 全年指标达成总览，表格呈现
3. 关键里程碑 — 时间线形式，重要节点 + 标志性事件
4. 不足与反思 — 未达预期项 + 原因分析 + 改进方向
5. 下年度方向 — 战略重点 + 关键目标 + 资源需求
6. 全年承诺闭环 — 年初承诺的完成情况总览

**数据要求：** 全年指标 + vs 目标 + vs 去年 + 行业对比。需要年度趋势。

**典型受众：** 高层 / HR（述职场景）

**与季度报告的区别：** 增加反思章节、里程碑时间线、个人/团队叙事弧线。篇幅更长。

---

## 转正述职

**目的：** 试用期成果展示，证明胜任当前岗位。

**必需章节：**
1. 试用期核心成果 — 按岗位职责逐项列出 + 数据佐证
2. 能力成长 — 从入职到当前的成长轨迹 + 具体案例
3. 不足与改进 — 自我认知 + 改进措施 + 时间计划
4. 未来计划 — 转正后 3-6 个月的工作方向 + 预期目标

**数据要求：** 产出数据 + 里程碑 + 评价反馈（如有）。

**典型受众：** 直属上级 / HR / 部门负责人

**与晋升述职的区别：** 侧重"胜任"——证明能做好当前岗位，不要求超越职级的影响力证据。

---

## 晋升述职

**目的：** 证明已达到下一职级要求，展示超越当前职级的影响力。

**必需章节：**
1. 核心贡献 — 3-5 个高影响力成果 + 量化数据 + 影响范围
2. 影响力证据 — 跨团队影响 / 行业影响 / 组织提升
3. 能力对标 — 逐项对标目标职级要求 + 佐证
4. 未来规划 — 下一职级的工作愿景 + 预期贡献

**数据要求：** 量化贡献 + 影响范围数据 + 对标职级要求的逐项证据。

**典型受众：** 晋升委员会 / 高层

**与转正述职的区别：** 侧重"超越"和"影响力"——不仅做好本职，还要展示对组织/团队的溢出效应。
