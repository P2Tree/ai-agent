# 数据源策略

## 有工具接入时

### 支持的数据源

| 工具 | 可获取数据 | 接入方式 |
|------|-----------|---------|
| 飞书 | 文档、多维表格、消息、日历 | MCP |
| 钉钉 | 审批、日志、消息、任务 | MCP |
| 企业微信 | 消息、审批、日程 | MCP |
| 腾讯文档 | 文档、表格 | MCP |
| 语雀 | 知识库文档 | MCP |
| Jira/项目管理系统 | 任务、进度、工时 | MCP |

### 数据采集流程

1. 确定报告覆盖的时间范围
2. 拉取该时间范围内的相关项目/文档/指标
3. 提取关键数据点（指标值、事件、状态变更）
4. 交叉验证数据一致性（不同来源的数据是否吻合）
5. 补充缺失的对比基准（上期值、目标值）

## 无工具接入时（默认路径）

大多数场景下用户未配置工具接入，此时采用引导式数据输入。

### 引导式数据输入

按以下清单引导用户提供数据。用户可以用任何格式回答——口语、截图、链接均可。

#### 必需数据

- [ ] 关键指标及数值
- [ ] 上期同指标数值（用于环比）
- [ ] 目标值（用于达成率）
- [ ] 重大事件/里程碑
- [ ] 风险/阻塞事项

#### 可选数据

- [ ] 行业基准
- [ ] 跨团队依赖状态
- [ ] 上期承诺清单

### 用户无法提供数据时的降级策略

1. 标注"待补充"并列出需要补充的具体数据项
2. 不留空——至少写明预期值和获取路径（如"数据来源：XX 系统，预计可于 X 日补充"）
3. 绝不编造数据
4. 如果核心指标完全缺失，提醒用户该指标对报告说服力的关键性，建议延后提交至数据就绪

### 引导话术示例

"为了生成有说服力的周报，我需要以下信息。你可以简单罗列，我会帮你整理成正式格式：

1. 这周完成了哪些事？（大概即可，我会追问细节）
2. 有哪些关键指标的数据？（数字即可，如 DAU、转化率等）
3. 上周这些指标是多少？
4. 下周计划做什么？
5. 有没有什么卡住的地方？"
