# 财务模型规范

创建财务模型时的配色、格式和公式规范。

## 配色标准

| 颜色 | RGB | 用途 |
|------|-----|------|
| 蓝色 | 0,0,255 | 硬编码输入值、用户可变假设 |
| 黑色 | 0,0,0 | 所有公式和计算 |
| 绿色 | 0,128,0 | 同工作簿跨工作表链接 |
| 红色 | 255,0,0 | 外部文件链接 |
| 黄色背景 | 255,255,0 | 需要关注的关键假设 |

## 数字格式

| 类型 | 格式 | 示例 |
|------|------|------|
| 年份 | 文本字符串 | "2024"（不是 2,024） |
| 货币 | `$#,##0` | $1,234 |
| 零值 | `$#,##0;($#,##0);"-"` | 显示为 - |
| 百分比 | `0.0%` | 15.0% |
| 乘数 | `0.0x` | 3.5x |
| 负数 | 括号表示 | (123) 而非 -123 |

货币列必须在标题中标注单位，如 "Revenue ($mm)"。

## 公式规则

### 假设放独立单元格

```python
# 错误
sheet['B5'] = '=B4*1.05'
# 正确：假设增长率在 B6 单元格
sheet['B5'] = '=B4*(1+$B$6)'
```

### 公式错误预防

- 验证所有单元格引用正确
- 检查范围偏移错误
- 确保公式在所有期间一致
- 测试边界情况（零值、负数）
- 确认无意外循环引用

### 硬编码值文档化

在旁边单元格或注释中标注来源，格式：`来源: [系统/文档], [日期], [具体参考]`

## 验证清单

- 测试 2-3 个引用确认拉取正确值
- 列映射确认（如第 64 列 = BL，不是 BK）
- 行偏移注意（DataFrame 行 5 = Excel 行 6）
- NaN 处理：用 `pd.notna()` 检查空值
- 除零检查：除法前确认分母
- 跨表引用格式正确（Sheet1!A1）
- 先在小范围测试公式，再批量应用
