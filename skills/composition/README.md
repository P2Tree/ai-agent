# Composition

内容生成相关的 skill。

## article-series-writer `[自动]`

按大纲并行写一系列文章，每篇独立写完自动审校和修订，形成闭环。不用一篇篇串行等。

**什么时候用：** 要批量写系列技术文章时。

**触发方式：** 当你明确说要批量写文章、写系列文章、或输入 `/article-series-writer` 会激活。

## doc-coauthoring `[自动]`

引导用户通过结构化工作流协作撰写文档（提案、技术规格、决策文档等）。三阶段：上下文收集 → 逐节精炼 → 读者测试。

**什么时候用：** 要写文档、提案、技术规格、决策文档、RFC 时。

**触发方式：** 当你提到要写文档、起草提案、创建规格，或输入 `/doc-coauthoring` 会激活。
