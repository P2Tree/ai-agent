## coauthoring `[自动]`

人机协作撰写文章、博客、随笔等 prose 类内容。三阶段：上下文收集 → 逐节精炼 → 读者测试。用户的想法和声音驱动输出，Claude 放大而非替代。

**什么时候用：** 要写博客、文章、随笔、教程，或任何需要自己声音驱动的内容时。

**触发方式：** 当你提到要写博客、写文章、写随笔，或输入 `/coauthoring` 会激活。

## work-report `[自动]`

生成符合国内企业汇报规范的结构化报告，覆盖日报/周报/月报/季报/年度总结/转正述职/晋升述职。数据驱动、表格优先、闭环必查。

**什么时候用：** 要写工作汇报、日报、周报、月报、季度报告、年度总结、转正述职、晋升述职时。

**触发方式：** 当你提到要写报告、述职，或输入 `/work-report` 会激活。
