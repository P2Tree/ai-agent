# Scenario Templates

## Resume (简历)

3-5 bullet points, each starting with an action verb.

```
**[Project Name]** | [Role] | [Time Range]

- [Action verb] [what was done], resulting in [quantified outcome]
  - [Technical detail demonstrating depth]
- [Action verb] [what was done], achieving [metric]
  - [Technical detail showing scope]
- [Action verb] [what was done], improving [metric] from [X] to [Y]
```

Action verbs (Chinese): 设计、实现、优化、重构、修复、扩展、搭建、主导
Action verbs (English): Designed, Implemented, Optimized, Refactored, Fixed, Extended, Built, Led

Each bullet should contain:
1. What was done (action + object)
2. Quantified result or impact
3. Key technical detail as sub-point (recommended)

## Interview (面试/口头描述)

STAR narrative, conversational tone, 2-3 minutes spoken.

Structure:
1. **Situation** (10-15s): 项目背景、团队构成、自己的角色
2. **Task** (10-15s): 面临的核心挑战或目标
3. **Action** (60-90s): 具体做了什么，技术选型的理由，遇到的困难
4. **Result** (15-30s): 量化成果、对团队/产品的影响

### Template

```
我在 [公司] [团队] 负责 [项目/模块]。[Situation]

这个项目的核心挑战是 [具体挑战]。[Task]

我的做法是 [具体技术方案]。过程中遇到了 [具体困难]，
我是这样解决的 [解决方式]。[Action - 展开 2-3 个重点]

最终 [量化成果]。[Result]
```

### Tips

- First person, present tense for ongoing, past tense for completed
- Use concrete numbers: "389 commits", "支持了 5 代 GPU"
- Name specific technologies: LLVM, C++, GPU architecture
- Show decision-making: not just what, but why
- Prepare 2-3 "deep dive" stories for follow-up questions

## Performance Review (述职)

Impact-focused with metrics and before/after comparisons.

```
**[Project Name] 述职**

## 核心贡献

| 序号 | 贡献 | 量化数据 | 影响范围 |
|------|------|---------|---------|
| 1 | [贡献1] | [数据] | [团队/部门/公司] |
| 2 | [贡献2] | [数据] | |
| 3 | [贡献3] | [数据] | |

## 技术深度

[在关键技术领域的深度和突破]

## 跨团队协作

| 协作事项 | 协作方 | 成果 |
|---------|-------|------|
| [事项1] | [团队] | [成果] |

## 未来规划

| 方向 | 预期目标 | 量化指标 |
|------|---------|---------|
| [方向1] | [目标] | [指标] |
```

### Key Differences from Resume

- More narrative, includes challenges and learnings
- Explicit before/after metrics where available
- Shows growth trajectory, not just snapshot
- Includes cross-team impact and collaboration
- Forward-looking section required

## General Introduction (通用介绍)

Balanced 1-2 paragraph overview.

```
[Project Name] 是 [一句话描述项目定位]。我在该项目中担任 [角色]，
主要负责 [2-3个核心职责]。

在 [时间范围] 期间，我累计提交 [N] 次，新增 [X] 行代码，
涵盖 [模块1]、[模块2]、[模块3] 等核心模块。
代表性工作包括 [1-2个最突出的贡献]。
```

### Key Principles

- Accessible to non-technical readers
- One paragraph for "what", one for "my role"
- No jargon without brief explanation
- Balanced breadth (scope) and depth (key achievements)
