# Productivity

提升效率但不直接写代码的 skill。

## brainstorming `[自动]`

写代码之前先对齐需求。通过提问把模糊的想法变成明确的设计方案，避免一上来就动手导致方向跑偏。支持可视化原型辅助讨论。

**什么时候用：**开始新功能、新项目、或大改动之前。

**触发方式：**agent 检测到你开始做新功能或大改动时自动触发。

**参考：**superpowers:brainstorming

## zoom-out `[手动]`

跳出代码细节，看全局：模块之间怎么依赖、谁调谁、这段代码在整体架构里的位置。用项目的领域词汇来描述，不是干巴巴的依赖图。

**什么时候用：**不熟悉某段代码，想了解它在全局中的位置时。

**触发方式：**手动激活，只能通过 `/zoom-out` 触发该 skill。

**参考：**mattpocock:zoom-out

## prototype `[自动]`

快速做个一次性原型来验证设计思路。逻辑原型用终端交互验证状态机，UI 原型做多个变体可切换。跑起来看效果，满意了再做正式版，不满意直接删。

**什么时候用：**想快速验证设计思路、数据模型、或 UI 方案时。

**触发方式：**当说"做个原型""试试几种方案""prototype this"时会激活。

**参考：**mattpocock:prototype

## caveman `[自动]`

极致压缩沟通内容——删掉填充词、冠词、客套话，只留技术要点。

**什么时候用：**想降低对话的 token 消耗时。

**触发方式：**需要你明确说"caveman mode""less tokens""be brief"或输入 `/caveman` 才会激活。激活后始终生效，直到你说 "stop caveman mode" 才会关闭。

**参考：**mattpocock:caveman

## grill-me `[自动]`

像面试一样逐个追问，帮你把模糊的想法理清楚。遍历决策树的每个分支逐个解决。对于能通过读代码回答的问题，不会提问。

**什么时候用：**有了个想法但还没想透，想让 agent 帮你捋清楚时。

**触发方式：**需要你说"grill me""帮我压力测试一下这个方案"或输入 `/grill-me` 才会激活。

**参考：**mattpocock:grill-me + mattpocock:grill-with-docs
