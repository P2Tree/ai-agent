# Career

职业发展相关的 skill。

## pre-view [自动]

模拟真实的多轮面试流程。审查简历和补充资料，生成虚拟公司背景，协商岗位 JD，然后进行 3 轮面试（技术面、主管面、领导面），每轮由不同人设的面试官 subagent 执行，最终输出客观的面试评价报告。

什么时候用：准备面试、练习面试技巧时。

触发方式：你说“模拟面试”“mock interview”“pre-view”或明确要求面试练习时自动激活。

## project-highlight [自动]

从 git 仓库中提取关键贡献，按场景整理成项目亮点描述——简历要点、面试口述、述职总结、通用项目介绍。数据从代码历史提取，不编造。

什么时候用：要写简历项目经验、准备面试项目描述、总结项目贡献、生成述职材料时。

触发方式：当你提到项目经验、简历项目、面试描述、述职描述时会激活。
