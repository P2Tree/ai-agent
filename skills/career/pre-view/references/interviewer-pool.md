# Interviewer Persona Pool

Each round has 3-4 personas. Select one per round without revealing to the candidate. The persona naturally manifests through question style, tone, and focus areas.

## Persona Schema

Each persona includes:

- **Name** — fictional but realistic
- **Title** — appropriate for the round's level
- **Personality tendency** — core trait that drives questioning style
- **Focus areas** — what this persona particularly values
- **Background** — one-sentence career background

## Selection Note

Select one persona per round. No cross-session deduplication mechanism — rely on natural agent randomness from the 3-4 persona pool. If the resume language is English, adapt persona names to be culturally appropriate for the generated company context (e.g., use Western names for a US-based company simulation).
